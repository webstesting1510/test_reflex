# Reflex Test Calculator

A small browser-based calculator created for Reflex usability testing.

## Expected behaviour

- Users can enter two numbers.
- Addition, subtraction, multiplication, and division should work.
- Empty or invalid values should show a clear error.
- Dividing by zero should show a clear error.
- The result should not show `NaN` or `Infinity`.

## Test task for Reflex

Review the calculator, fix validation issues, and keep the existing layout simple.
